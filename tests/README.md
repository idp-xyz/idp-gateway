黑盒用例和 `integration/` 下的各套用例通过都不改变验收矩阵里任何用例的 `NOT_RUN`。验收用例离开 `NOT_RUN` 时必须填写指向仓库内文件的 `evidence_uri`。

诊断采集的参考实现仍在 `scripts/`，还没有移植成 Go。RouteIntent 预检已有 Go 移植（`internal/routecompile`），`scripts/preflight_intents.py` 还在，契约测试仍用它的反例。出站判定规则的 Go 版本在 `internal/egressauthz/domain`。按账户限流在同一上下文。承运商熔断在 `internal/providersigner/domain`。JWKS 同步在 `internal/jwkssync`。
