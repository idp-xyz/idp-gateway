# ADR-0007 — 零信任策略与失败默认拒绝

> **状态**：Proposed（待具名批准） · **版本** V1.0 · **日期** 2026-11-10  
> 本 ADR 为设计建议，不是已经执行的技术审批、生产基线或运行验收。

## 背景

IDP 在取消独立 BIP 规划后，需要为 CargoPai、Parcel、Brant、Prism 和 TELOS 建立清晰的 API 安全与协议路由边界，避免供应商认证信息散落在业务代码、单一网关池形成集中故障或 Fabric 越界成为运行数据面。

## 推荐决策

JWT 验证与 Request-level/Backend-level ExtAuthZ 以明确 Policy 运行；高风险凭证调用失败拒绝；非幂等业务请求代理层无默认重试。

## 为什么这样决定

避免越权和跨租户 Token 滥用以及重复创建面单/报关。

## 被考虑的替代方案

授权依赖故障时 fail-open / Gateway 自动重试所有 POST。

## 成本与剩余风险

影响可用性，需要缓存可用性预算和业务层恢复设计，安全负责人批准缓存策略。

## 变更与回退条件

需由架构负责人、对应产品 Owner、安全负责人及运行负责人具名复核；在相关 PoC、负向测试、容量与灾备验证未完成前保持 Proposed。若试验证明性能、安全、可运维性无法满足受批准目标，重新评估而非自动维持选型。
