# ADR-0001 — agentgateway 作为首选数据面实现

> **状态**：Proposed（待具名批准） · **版本** V1.0 · **日期** 2026-11-10  
> 本 ADR 为设计建议，不是已经执行的技术审批、生产基线或运行验收。

## 背景

IDP 在取消独立 BIP 规划后，需要为 CargoPai、Parcel、Brant、Prism 和 TELOS 建立清晰的 API 安全与协议路由边界，避免供应商认证信息散落在业务代码、单一网关池形成集中故障或 Fabric 越界成为运行数据面。

## 推荐决策

以 agentgateway 官方开源版本构建 HTTP/gRPC/AI 流量代理；不自研 Go 通用反向代理；并保留替代数据面适配的能力。

## 为什么这样决定

HTTP+LLM/MCP/A2A 的共性能力与已有官方 ExtAuthZ、Backend Auth；同产品各协议共用技术但不共享安全故障域。

## 被考虑的替代方案

Traefik Proxy、Apache APISIX、从零 Go ReverseProxy。

## 成本与剩余风险

第三方动态 Token 注入/多副本运行/版本兼容未经实测；生产批准仍须 PoC；若失败，回退至可插拔 Traefik/APISIX。

## 变更与回退条件

需由架构负责人、对应产品 Owner、安全负责人及运行负责人具名复核；在相关 PoC、负向测试、容量与灾备验证未完成前保持 Proposed。若试验证明性能、安全、可运维性无法满足受批准目标，重新评估而非自动维持选型。
